# Changelog

## 1.0.0 — 2026-09-06

First public release / 首个公开版本。

- Blender-built iPod with native SceneKit rendering.
- Classic monochrome LCD, click-wheel navigation, sounds and 3D rotation.
- Read-only local Codex library, search, folders, pinned/archive filters and automatic refresh.
- Simplified Chinese interface, bilingual documentation, editable model and reproducible build scripts.
- Apple Silicon build, macOS 14 deployment target, ad-hoc signing.
